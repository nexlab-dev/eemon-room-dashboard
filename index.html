⚙️ データ管理・使い方

GitHub Pagesの無料ホスティングに、公開しても問題ない商品情報だけを置く。承認状態はこのiPhone内に保存し、GitHubや楽天へ送信しない。Safariの履歴削除で消える場合があるで。

アプリ風に使うならSafariの共有メニューから「ホーム画面に追加」。このページに楽天IDやパスワードは入力しないでな。
